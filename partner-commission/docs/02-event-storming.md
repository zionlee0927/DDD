# 02. Event Storming

> Event Storming 순서: 이벤트 → 커맨드 + 액터 → 정책

---

## 도메인 이벤트

### 추적 영역

| # | 이벤트 | 설명 |
|---|--------|------|
| 1 | 추적 링크가 생성되었다 | 파트너용 추적 URL 발급 |
| 2 | 추천 코드가 생성되었다 | 파트너용 추천 코드 발급 |
| 3 | 클릭이 기록되었다 | 소비자가 추적 링크를 클릭 |

### 귀속 영역

| # | 이벤트 | 설명 |
|---|--------|------|
| 4 | 전환 이벤트가 수신되었다 | 고객사가 전환 발생을 알림 |
| 5 | 귀속이 판정되었다 | 전환을 특정 파트너에게 매칭 완료 (ATTRIBUTED) |
| 6 | 귀속이 실패했다 | 매칭할 클릭/쿠폰이 없음 (UNATTRIBUTED) |
| 7 | 취소 이벤트가 수신되었다 | 고객사가 전환 취소를 알림 |
| 8 | 귀속이 철회되었다 | 취소로 인해 귀속 무효화 (REVOKED) |

### 커미션 영역

| # | 이벤트 | 설명 |
|---|--------|------|
| 9 | 커미션이 산정되었다 | 귀속 판정 후 규칙에 따라 금액 계산 (PENDING) |
| 10 | 커미션이 확정되었다 | 확정 조건 충족 (CONFIRMED) |
| 11 | 커미션이 취소되었다 | 귀속 철회로 인한 무효화 (CANCELLED) |
| 12 | 차감이 생성되었다 | 이미 확정/정산된 커미션의 취소 → 차감 기록 |

### 정산 명세 영역

| # | 이벤트 | 설명 |
|---|--------|------|
| 13 | 정산 주기가 마감되었다 | 정산 기간 종료 |
| 14 | 명세서가 생성되었다 | 파트너별 정산 명세 생성 완료 |

### 파트너 영역

| # | 이벤트 | 설명 |
|---|--------|------|
| 15 | 파트너가 가입했다 | 플랫폼에 계정 생성 |
| 16 | 파트너가 프로그램에 소속되었다 | 특정 테넌트에 참여 |
| 17 | 티어가 변경되었다 | 실적에 따라 등급 변동 |

### 테넌트 영역

| # | 이벤트 | 설명 |
|---|--------|------|
| 18 | 테넌트가 등록되었다 | 고객사 가입 |
| 19 | API 키가 발급되었다 | 인증 키 생성 |
| 20 | 프로그램 설정이 변경되었다 | 귀속/커미션/정산 규칙 변경 |

### 알림 영역

| # | 이벤트 | 설명 |
|---|--------|------|
| 21 | 웹훅이 발송되었다 | 고객사에게 결과 통보 |

## 커맨드 + 액터

### 추적 영역

| 액터 | 커맨드 | 이벤트 |
|------|--------|--------|
| 고객사 (API) | 추적 링크 생성하기 | 추적 링크가 생성되었다 |
| 고객사 (API) | 추천 코드 생성하기 | 추천 코드가 생성되었다 |
| 소비자 (브라우저) | 추적 링크 클릭하기 | 클릭이 기록되었다 |

### 귀속 영역

| 액터 | 커맨드 | 이벤트 |
|------|--------|--------|
| 고객사 (API) | 전환 이벤트 전송하기 | 전환 이벤트가 수신되었다 |
| 정책 | 귀속 판정하기 | 귀속이 판정되었다 / 귀속이 실패했다 |
| 고객사 (API) | 취소 이벤트 전송하기 | 취소 이벤트가 수신되었다 |
| 정책 | 귀속 철회하기 | 귀속이 철회되었다 |

### 커미션 영역

| 액터 | 커맨드 | 이벤트 |
|------|--------|--------|
| 정책 | 커미션 산정하기 | 커미션이 산정되었다 |
| 정책 / 고객사 (API) | 커미션 확정하기 | 커미션이 확정되었다 |
| 정책 | 커미션 취소하기 | 커미션이 취소되었다 |
| 정책 | 차감 생성하기 | 차감이 생성되었다 |

### 정산 명세 영역

| 액터 | 커맨드 | 이벤트 |
|------|--------|--------|
| 스케줄러 | 정산 주기 마감하기 | 정산 주기가 마감되었다 |
| 정책 | 명세서 생성하기 | 명세서가 생성되었다 |

### 파트너 영역

| 액터 | 커맨드 | 이벤트 |
|------|--------|--------|
| 파트너 | 가입하기 | 파트너가 가입했다 |
| 파트너 / 고객사 | 프로그램 참여하기 | 파트너가 프로그램에 소속되었다 |
| 정책 | 티어 재평가하기 | 티어가 변경되었다 |

### 테넌트 영역

| 액터 | 커맨드 | 이벤트 |
|------|--------|--------|
| 고객사 | 테넌트 등록하기 | 테넌트가 등록되었다 |
| 고객사 | API 키 발급하기 | API 키가 발급되었다 |
| 고객사 | 프로그램 설정 변경하기 | 프로그램 설정이 변경되었다 |

## 정책 (이벤트 → 커맨드 자동 연결)

```
전환 이벤트가 수신되었다       → [정책] 귀속 판정하기
취소 이벤트가 수신되었다       → [정책] 귀속 철회하기
귀속이 판정되었다             → [정책] 커미션 산정하기
귀속이 철회되었다 (PENDING)   → [정책] 커미션 취소하기
귀속이 철회되었다 (CONFIRMED) → [정책] 차감 생성하기
귀속이 철회되었다 (SETTLED)   → [정책] 차감 생성하기
확정 이벤트 수신 or 14일 경과  → [정책] 커미션 확정하기
정산 주기가 마감되었다         → [정책] 명세서 생성하기
명세서가 생성되었다           → [정책] 웹훅 발송하기
```

## 이벤트 흐름

### 정상 흐름

```
추적 링크 생성 → 소비자 클릭 (클릭 기록)
→ 고객사가 전환 이벤트 전송
→ 귀속 판정 (파트너 매칭)
→ 커미션 산정 (PENDING)
→ 확정 조건 충족 → 커미션 확정 (CONFIRMED)
→ 정산 주기 마감 → 명세서 생성 → 웹훅 발송
```

### 취소 — PENDING 상태에서

```
고객사가 취소 이벤트 전송
→ 귀속 철회
→ 커미션 취소 (PENDING → CANCELLED)
→ 명세서에 포함되지 않음
```

### 취소 — CONFIRMED 상태에서

```
고객사가 취소 이벤트 전송
→ 귀속 철회
→ 차감 생성 (다음 명세서에서 마이너스)
```

### 귀속 실패

```
고객사가 전환 이벤트 전송
→ 귀속 판정 시도 → 매칭할 클릭/쿠폰 없음 (윈도우 만료 등)
→ 귀속 실패 (UNATTRIBUTED)
→ 커미션 산정 없음
```

### 쿠폰코드 기반 귀속

```
추천 코드 생성 → 파트너가 오프라인에서 코드 공유
→ 고객사가 전환 이벤트 전송 (referral_code 포함)
→ 귀속 판정 (추천 코드 → 파트너 매칭)
→ 커미션 산정
```

---

## 설계 결정 사항

- **귀속 판정 시점:** 전환 이벤트 수신 즉시. 배치 아님.
- **귀속 증거 우선순위:** 클릭 vs 쿠폰 충돌 시 테넌트 설정에 따름 (기본: 쿠폰 우선).
- **커미션 확정 기본값:** 고객사가 확정 이벤트를 보내면 즉시, 안 보내면 14일 후 자동 확정.
- **확정 후 취소:** CANCELLED로 전이하지 않고 Deduction(차감) 생성. 다음 명세서에 반영.
- **정산 주기:** 테넌트가 설정 (기본: 월간). 스케줄러가 마감 트리거.
- **티어 재평가:** 명세서 생성 후 실적 기반으로 트리거 (추후 구체화).
