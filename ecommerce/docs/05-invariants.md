# 05. 불변식 (Invariant) 식별

> "불변식은 Aggregate 내부에서 어떤 상황에서든 항상 참이어야 하는 규칙이다. 이것이 Aggregate 경계를 결정한다."

---

## 식별 과정

### 입력

- 4단계 Entity/VO의 **속성**
- 2단계 이벤트의 **상태 전이**
- 2단계 커맨드의 **실행 조건**

### 불변식을 찾는 5가지 소스

| 소스             | 질문                            | 예시                       |
|----------------|-------------------------------|--------------------------|
| Entity 속성     | 이 값에 허용 범위가 있는가?           | 수량 ≥ 1, 금액 ≥ 0          |
| Entity 간 관계   | 함께 지켜야 할 정합성이 있는가?        | totalAmount = items 합계    |
| 상태 전이        | 어떤 상태에서 어떤 상태로만 갈 수 있는가? | CREATED → PAID만 가능       |
| 커맨드 실행 조건  | 이 행위가 실행되려면 뭐가 보장되어야 하는가? | 주문 생성 시 아이템 1개 이상     |
| Entity 간 경계   | 트랜잭션 범위에서 깨지면 안 되는 것은?   | 정산 금액 = 포함 커미션 합계     |

### 판단 기준: 불변식 vs 정책

| 구분   | 불변식 (Invariant)              | 정책 (Policy)              |
|--------|-------------------------------|--------------------------|
| 범위   | Aggregate **내부**             | Aggregate **간**           |
| 보장   | 같은 트랜잭션에서 항상 참            | 결과적 일관성 (비동기)          |
| 위반 시 | 즉시 거부 (예외 발생)              | 보상 트랜잭션으로 복구           |
| 예시   | 재고 ≥ 0                       | 주문 확정 → 재고 차감          |

## 분류 결과

## Partner BC

| #  | 불변식                          | 설명                        |
|----|-------------------------------|---------------------------|
| P1 | 파트너 이메일은 유일해야 한다          | 중복 가입 방지                  |
| P2 | 티어는 유효한 등급만 가능하다          | BRONZE, SILVER, GOLD 중 하나  |
| P3 | 비활성 파트너는 추적 링크를 생성할 수 없다 | status가 ACTIVE일 때만 링크 발급  |

## Tracking BC

| #  | 불변식                                    | 설명                          |
|----|----------------------------------------|-------------------------------|
| T1 | 추적 링크의 trackingCode는 유일해야 한다       | 중복 코드 방지                    |
| T2 | 만료된 추적 링크로는 클릭이 기록되지 않는다        | 만료 체크                       |
| T3 | 귀속 기간(AttributionWindow) 내 클릭만 귀속 대상 | 30일 지난 클릭은 귀속 불가           |
| T4 | 하나의 주문에 대해 귀속 판정은 1회만 가능하다      | 중복 판정 방지                    |
| T5 | 상태 전이: PENDING → CONFIRMED 또는 PENDING → REVOKED만 가능 | CONFIRMED/REVOKED에서 되돌릴 수 없음 |

## Commission BC

| #  | 불변식                                  | 설명                          |
|----|---------------------------------------|-------------------------------|
| C1 | 커미션 금액은 0보다 커야 한다                 | 음수/0원 커미션 불가               |
| C2 | 커미션 금액 ≤ 주문 금액                    | 주문 금액 초과 커미션 불가            |
| C3 | CONFIRMED 상태에서만 정산(SETTLED) 가능     | 미확정 커미션은 정산 불가             |
| C4 | CANCELLED 커미션은 정산에 포함될 수 없다      | 취소된 건 제외                    |
| C5 | Settlement.totalAmount = 포함된 커미션 합계 | 정산 금액 정합성                   |
| C6 | 정산 완료(COMPLETED) 후 포함 커미션 변경 불가  | 확정된 정산은 불변                  |

## Order BC

| #   | 불변식                                    | 설명                          |
|-----|----------------------------------------|-------------------------------|
| O1  | 주문은 최소 1개 이상의 OrderItem을 가져야 한다   | 빈 주문 불가                     |
| O2  | totalAmount = 모든 OrderItem (price × quantity) 합계 | 금액 정합성                |
| O3  | OrderItem의 price는 0 이상이어야 한다        | 프리기프트 가능, 음수 불가            |
| O4  | OrderItem의 quantity는 1 이상이어야 한다     | 0개 주문 불가                    |
| O5  | PAID 상태에서만 CANCEL_REQUESTED 가능      | 결제 완료된 주문만 취소 요청 가능        |
| O6  | CREATED에서만 PAID 전이 가능               | 이미 취소된 주문은 확정 불가           |
| O7  | CREATED 또는 CANCEL_REQUESTED에서만 CANCELLED 가능 | 상태 전이 순서 보장         |
| O8  | 주문 생성 시 가격은 스냅샷으로 고정된다           | 이후 상품 가격 변동 영향 없음          |
| O9  | 하나의 주문에 같은 상품이 중복될 수 없다          | productId 유니크               |
| O10 | 모든 OrderItem이 CANCELLED면 주문 전체 CANCELLED | 부분 취소 → 전체 취소 전이      |

## Cart BC

| #   | 불변식                              | 설명                    |
|-----|------------------------------------|-----------------------|
| CT1 | CartItem 수량은 1 이상이어야 한다        | 0이면 제거               |
| CT2 | 같은 상품은 하나의 CartItem으로 관리된다    | 중복 불가, 수량 합산         |
| CT3 | Cart는 한 고객에 하나만 존재한다           | customerId 유니크        |
| CT4 | CartItem의 price는 0 이상이어야 한다     | 음수 불가                |

## Catalog BC

| #   | 불변식                          | 설명                    |
|-----|-------------------------------|------------------------|
| CA1 | 상품 가격은 0 이상이어야 한다         | 음수 불가                 |
| CA2 | 상품명은 비어있을 수 없다            | 필수값                   |
| CA3 | 품절(SOLD_OUT) 상품은 판매 불가     | 장바구니 담기/주문 시 체크      |

## Inventory BC

| #   | 불변식                                        | 설명                      |
|-----|----------------------------------------------|-------------------------|
| I1  | availableQuantity = totalQuantity - heldQuantity | 가용 재고 정합성             |
| I2  | availableQuantity ≥ 0                         | 음수 재고 불가              |
| I3  | heldQuantity ≥ 0                              | 음수 선점 불가              |
| I4  | 선점(Hold) 수량 ≤ availableQuantity             | 가용 재고 초과 선점 불가       |
| I5  | 확정 차감은 선점된 수량에서만 가능                    | 선점 없이 차감 불가           |

## Payment BC

| #   | 불변식                                | 설명                      |
|-----|--------------------------------------|-------------------------|
| PM1 | 결제 금액은 0보다 커야 한다                | 0원 결제 불가               |
| PM2 | 하나의 주문에 중복 결제 불가                 | 이미 COMPLETED면 재결제 불가   |
| PM3 | 환불은 COMPLETED 상태에서만 가능           | PENDING/FAILED는 환불 대상 아님 |
| PM4 | 환불 금액 ≤ 결제 금액                    | 초과 환불 불가               |
| PM5 | REFUNDED는 COMPLETED에서만 전이 가능     | 상태 전이 순서 보장            |
| PM6 | FAILED에서 COMPLETED로 전이 불가         | 실패한 결제는 재시도(새 Payment) |

## Shipping BC

| #   | 불변식                                  | 설명                      |
|-----|----------------------------------------|-------------------------|
| S1  | 배송 시작은 주문 확정(PAID) 후에만 가능        | 미결제 주문 배송 불가           |
| S2  | DELIVERED 후 상태 변경 불가                | 배송 완료는 최종 상태           |
| S3  | 운송장 번호는 SHIPPED 이후에만 존재           | 출고 전에는 번호 없음           |
| S4  | 상태 전이: PREPARING → SHIPPED → IN_TRANSIT → DELIVERED | 순서 보장 |

## Promotion BC

| #   | 불변식                                  | 설명                      |
|-----|----------------------------------------|-------------------------|
| PR1 | 쿠폰 사용 횟수(usedCount) ≤ 사용 한도(usageLimit) | 초과 사용 불가          |
| PR2 | 만료된 쿠폰(EXPIRED)은 적용 불가             | validTo 이후 사용 불가        |
| PR3 | 소진된 쿠폰(EXHAUSTED)은 적용 불가           | 한도 도달 시 자동 소진         |
| PR4 | 할인 금액 ≤ 주문 금액                       | 주문 금액 초과 할인 불가        |
| PR5 | 최소 주문 금액 미달 시 쿠폰 적용 불가           | minOrderAmount 체크        |

## 상태 전이도

### Order
```
CREATED → PAID → SHIPPED → DELIVERED
   ↓        ↓
CANCELLED  CANCEL_REQUESTED → CANCELLED
```

### Payment
```
PENDING → COMPLETED → REFUNDED
   ↓
FAILED
```

### Shipping
```
PREPARING → SHIPPED → IN_TRANSIT → DELIVERED
```

### Commission
```
PENDING → CONFIRMED → SETTLED
   ↓         ↓
CANCELLED  CANCELLED
```

### Attribution
```
PENDING → CONFIRMED
PENDING → REVOKED
```
