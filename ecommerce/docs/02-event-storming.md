# 02. Event Storming

> Event Storming 순서: 이벤트 → 커맨드 + 액터 → 정책

## 정책 (이벤트 → 커맨드 자동 연결)

```
주문이 생성되었다           → [정책] 재고 선점하기
재고가 선점되었다           → [정책] 결제 요청하기
재고 선점이 실패했다         → [정책] 주문 취소하기 (품절)
결제가 완료되었다           → [정책] 주문 확정하기
결제가 실패했다             → [정책] 주문 취소하기
결제가 실패했다             → [정책] 재고 선점 해제하기
재고 선점 10분 타임아웃     → [정책] 재고 선점 해제하기
재고 선점 10분 타임아웃     → [정책] 주문 취소하기
주문이 확정되었다           → [정책] 배송 시작하기
주문이 확정되었다           → [정책] 귀속 판정하기 (Tracking BC, PENDING 생성)
주문이 확정되었다           → [정책] 카트에서 해당 상품 제거 (Cart BC)
배송이 시작되었다           → [정책] 재고 확정 차감하기 (Inventory BC)
귀속이 판정되었다           → [정책] 커미션 산정하기 (Commission BC)
주문 취소가 요청되었다      → [정책] 환불 처리하기
환불이 처리되었다           → [정책] 주문 취소 확정하기
주문 취소가 확정되었다      → [정책] 재고 복원하기
주문 취소가 확정되었다      → [정책] 귀속 철회하기 (Tracking BC, PENDING → REVOKED)
귀속이 철회되었다           → [정책] 커미션 취소하기 (Commission BC)
배송이 완료되었다           → [정책] 귀속 확정하기 (Tracking BC, PENDING → CONFIRMED)
귀속이 확정되었다           → [정책] 커미션 확정하기 (Commission BC)
정산 주기 도래              → [정책] 정산 실행하기
정산이 완료되었다           → [정책] 티어 재평가하기
```

## 이벤트 흐름

### 정상 흐름

```
추적 링크 클릭 → 장바구니 담기 → 주문 생성 (귀속 정보 포함)
→ 재고 선점 → 결제 요청 → 결제 완료
→ 주문 확정 + 커미션 산정
→ 배송 시작 → 재고 확정 차감 → 배송 완료
→ (환불 기간 대기) → 커미션 확정
→ (정산 주기 도래) → 정산 완료 → 티어 재평가
```

### 결제 실패

```
주문 생성 → 재고 선점 → 결제 요청 → 결제 실패
→ 주문 취소 + 재고 선점 해제
```

### 품절 (재고 선점 실패)

```
주문 생성 → 재고 선점 시도 → 가용 재고 부족
→ 재고 선점 실패 → 주문 취소
```

### 재고 선점 타임아웃

```
주문 생성 → 재고 선점 → 결제 요청 → (10분 경과, 결제 미완료)
→ 재고 선점 해제 + 주문 취소
```

### 결제 후 취소

```
주문 확정 상태 → 주문 취소 요청 → 환불 처리 → 주문 취소 확정
→ 재고 복원 + 귀속 철회 → 커미션 취소
```

## 설계 결정 사항

- **귀속 판정 시점:** 주문 확정 이벤트를 Tracking BC가 구독하여 AttributionDecision 생성 (PENDING). 배송 완료 시 CONFIRMED. 주문 취소 시 REVOKED. Commission은 AttributionDecision 상태를 따라감.
- **귀속 데이터 정합성:** 클릭 기록은 주문 생성 전에 이미 저장되어 있으므로 유실 위험 없음. 주문에 trackingCode를 포함하여 전달.
- **재고 선점:** 결제 전 Hold → 결제 완료 시 확정. 타임아웃(10분) 시 자동 해제.
- **커미션 확정 시점:** 배송 완료 + 환불 기간 경과 후. 조기 확정 시 환불로 인한 손실 위험.
- **티어 재평가 트리거:** 정산 완료 시 (구체적 이벤트 연결).
- **반품 시 커미션 회수:** 향후 확장. 단, 정산 설계 시 "이미 지급된 커미션 차감(Deduction)" 구조는 미리 고려.
- **카트 상품 제거 시점:** 주문 확정(결제 완료) 시 Cart에서 해당 상품 제거. 주문 생성 시점 아님.
- **결제 후 취소 시 카트 복원:** 안 함. 유저가 다시 담아야 함. (가격 변동/품절 문제 회피)
