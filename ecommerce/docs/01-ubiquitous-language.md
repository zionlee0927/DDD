# 01. 유비쿼터스 언어 / 용어집

> "유비쿼터스 언어는 Bounded Context 내에서만 유효하다. 이 용어가 코드에 그대로 반영된다."

---

## 파트너(인플루언서) 영역

| 한국어    | 영문 (코드)             | 정의                           |
|--------|---------------------|------------------------------|
| 파트너    | Partner             | 상품을 추천하고 커미션을 받는 인플루언서       |
| 파트너 등록 | PartnerRegistration | 인플루언서가 우리 플랫폼에 가입하는 행위       |
| 티어     | Tier                | 파트너 등급 (실적에 따라 커미션율 차등)      |
| 추적 링크  | TrackingLink        | 파트너별 고유 URL. 이 링크를 통한 유입을 추적 |
| 추적 코드  | TrackingCode        | 추적 링크에 포함된 고유 식별 코드          |

## 귀속(Attribution) 영역

| 한국어    | 영문 (코드)             | 정의                            |
|--------|---------------------|-------------------------------|
| 귀속     | Attribution         | 특정 주문이 어떤 파트너의 추천 덕분인지 판정하는 것 |
| 클릭     | Click               | 소비자가 추적 링크를 클릭한 이벤트           |
| 귀속 기간  | AttributionWindow   | 클릭 후 구매까지 인정하는 기간 (예: 30일)    |
| 라스트 클릭 | LastClick           | 구매 직전 마지막 클릭한 파트너에게 귀속하는 방식   |
| 귀속 판정  | AttributionDecision | 주문에 대해 어떤 파트너에게 귀속할지 결정한 결과   |

## 커미션 정산 영역

| 한국어    | 영문 (코드)                | 정의                           |
|--------|------------------------|------------------------------|
| 커미션    | Commission             | 파트너가 받는 추천 수수료               |
| 커미션 규칙 | CommissionRule         | 커미션 계산 방식 (정률 %, 정액, 티어별 차등) |
| 정산     | Settlement             | 확정된 커미션을 파트너에게 지급하는 행위       |
| 정산 주기  | SettlementCycle        | 정산 빈도 (월 1회, 주 1회 등)         |
| 정산 대기  | PendingSettlement      | 귀속 확정되었으나 아직 지급 전인 커미션       |
| 정산 확정  | SettlementConfirmed    | 지급이 완료된 상태                   |
| 커미션 취소 | CommissionCancellation | 주문 취소로 인해 산정된 커미션을 무효화하는 행위  |

## 주문 영역

| 한국어   | 영문 (코드)     | 정의                                           |
|-------|-------------|----------------------------------------------|
| 주문    | Order       | 소비자의 구매 요청 (귀속 정보 포함)                        |
| 주문 항목 | OrderItem   | 주문 내 개별 상품 (상품, 수량, 가격)                      |
| 주문 상태 | OrderStatus | CREATED, PAID, SHIPPED, DELIVERED, CANCELLED |
| 환불    | Refund      | 결제 완료된 주문을 취소하고 금액을 돌려주는 행위                  |

## 상품 영역

| 한국어  | 영문 (코드)  | 정의         |
|------|----------|------------|
| 상품   | Product  | 판매 가능한 아이템 |
| 가격   | Price    | 상품의 판매 금액  |
| 카테고리 | Category | 상품 분류      |

## 장바구니 영역

| 한국어     | 영문 (코드)  | 정의                    |
|---------|----------|-----------------------|
| 장바구니    | Cart     | 소비자가 구매 전 상품을 담아두는 공간 |
| 장바구니 항목 | CartItem | 장바구니 내 개별 상품 (상품, 수량) |

## 결제 영역

| 한국어   | 영문 (코드)        | 정의                  |
|-------|----------------|---------------------|
| 결제    | Payment        | 주문에 대해 금액을 지불하는 행위  |
| 결제 수단 | PaymentMethod  | 카드, 계좌이체 등          |
| PG    | PaymentGateway | 외부 결제 대행사 (토스, 페이팔) |

## 재고 영역

| 한국어   | 영문 (코드) | 정의                                |
|-------|---------|-----------------------------------|
| 재고    | Stock   | 상품의 판매 가능 수량                      |
| 선점    | Hold    | 결제 전 재고를 임시 확보하는 행위 (다른 유저가 못 사게) |
| 선점 해제 | Release | 결제 실패/타임아웃 시 선점을 풀어 다시 판매 가능하게    |
| 확정 차감 | Confirm | 결제 완료 후 선점을 확정 차감으로 전환            |
| 복원    | Restore | 취소 시 재고를 되돌리는 행위                  |

## 배송 영역

| 한국어    | 영문 (코드)        | 정의                                        |
|--------|----------------|-------------------------------------------|
| 배송     | Shipment       | 주문 상품을 소비자에게 전달하는 과정                      |
| 배송 상태  | ShipmentStatus | PREPARING, SHIPPED, IN_TRANSIT, DELIVERED |
| 운송장 번호 | TrackingNumber | 물류사가 발급한 배송 추적 번호                         |

## 프로모션 영역

| 한국어   | 영문 (코드)      | 정의                    |
|-------|--------------|-----------------------|
| 쿠폰    | Coupon       | 할인을 적용할 수 있는 코드       |
| 할인 규칙 | DiscountRule | 할인 조건과 금액/비율          |
| 캠페인   | Campaign     | 특정 기간 동안 진행되는 프로모션 묶음 |
